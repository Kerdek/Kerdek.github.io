Lambda Calculus as a Proof System

Overview

The Curry-Howard correspondence relates logical proofs and lambda terms: propositions are types, proofs are programs. We obtain a proof system by encoding proofs as typed lambda calculus terms.

Core Principle

Each logical construct maps to a computational one:

Four Rules of Inference

Conditional Proof (→ Introduction)

Logical form: Assuming premise P, Q. So, P → Q.

Proof term: Lambda abstraction which proves P -> Q:

premise <i> : P.E

This is a conditional proof on premise <i> : P of proof E : Q.

Judgment rule:

<i> must not be bound in Γ, P must be closed in Γ, and E must prove Q in Γ, <i> : P.

<i> ∉ Γ

Γ ⊢ P

Γ, <i> : P ⊢ E : Q

Γ ⊢ premise <i> : P.E : P -> Q

Mechanics: premise <a> : t. discharges the antecedent t -> in the goal and introduces a premise <a> : t in the context. The body uses these like function parameters.

Example:

theorem <syllogism> : \/a b.a -> (a -> b) -> b := given a b. premise <a> : a. premise <ab> : a -> b. <ab> <a>.

The body <ab> <a> proves b for arbitrary propositions a and b and premises <a> : a and <ab> : a -> b.

Modus Ponens (→ Elimination)

Logical form: P → Q and P. So, Q.

Proof term: Function application which proves Q:

E F

This is a modus ponens through proof E : P -> Q from proof F : P.

Judgment rule:

F must prove P, and E must prove P -> Q in Γ.

Γ ⊢ F : P

Γ ⊢ E : P -> Q

Γ ⊢ E F : Q

Mechanics: When <ab> : a -> b and <a> : a, <ab> <a> proves b. This applies the proof to specific premises.

Generalization (∀ Introduction)

Logical form: Given arbitrary i, P. So, ∀i.P.

Proof term: Type abstraction which proves \/i.P:

given i.E

This is a generalization over given i of proof E : P.

Judgment rule:

i must not be bound in Γ, and E must prove P[j := i] in Γ, i.

i ∉ Γ

Γ, i ⊢ E : P[j := i]

Γ ⊢ given i.E : \/j.P

Mechanics: given a. discharges the universal quantifier \/a. in the goal and introduces an arbitrary a in the context. The body uses these like type parameters.

Example:

theorem <implication reflexive> : \/a.a -> a := given a. premise <a> : a. <a>.

The body premise <a> : a.<a> proves a -> a for arbitrary a.

Specialization (∀ Elimination)

Logical form: ∀i.P. So, P[i := T] for arbitrary T.

Proof term: Type application which proves P[i := T].

E Q

This is a specialization of proof E : P for proposition Q.

Judgment rule:

Q must be closed in Γ, and E must prove \/i.P in Γ.

Γ ⊢ Q

Γ ⊢ E : \/i.P

Γ ⊢ E Q : P[i := Q]

Mechanics: When <a> : \/i.a -> i, <a> t proves a -> t. This instantiates the proof for specific propositions.

Examples:

theorem <false of false> : false -> false := <implication reflexive> false

Interaction Between Rules

The power emerges from composing these rules.

theorem <congruent argument> : \/c a b.eq a b -> eq (c a) (c b) := given c a b. <congruent> (\b. eq (c a) (c b)) \. <equality reflexive> (c a).

Analysis:

  • given c a b. abstracts over three type variables
  • <congruent> is a universal proof, specialized for \b. eq (c a) (c b)
  • The \. operator applies this specialized proof to <equality reflexive> (c a)
  • Normalization at the type level constructs the desired equality

Contexts

Each given and premise extends the typing context. Proof judgment maintains a stack:

theorem <congruent argument> : \/c a b.eq a b -> eq (c a) (c b) := -- Γ ⊢ \/c a b.eq a b -> eq (c a) (c b) given c a b. -- Γ, c, a, b ⊢ eq a b -> eq (c a) (c b) <congruent> (\b. eq (c a) (c b)) \. -- Γ, c, a, b ⊢ eq (c a) (c a) <equality reflexive> (c a).

Summary

This calculus makes proof judgment semi-decidable: writing a proof is writing a well-typed program. Type soundness guarantees logical soundness. If a term type-checks, it represents a valid proof of its type-as-proposition.
